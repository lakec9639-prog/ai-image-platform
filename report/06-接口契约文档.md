# 6. 接口契约文档

## 6.1 通用约定

### 6.1.1 请求地址

```
开发环境: http://localhost:8080/api
生产环境: https://api.example.com/api
```

### 6.1.2 统一响应格式

所有接口返回统一的 JSON 结构：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": { }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 业务状态码，200 成功，非 200 失败 |
| message | String | 提示信息 |
| data | Object | 响应数据，失败时为 null |

### 6.1.3 状态码定义

| code | 含义 | 说明 |
|------|------|------|
| 200 | 成功 | 请求处理成功 |
| 400 | 参数错误 | 请求参数校验失败 |
| 401 | 未登录/已过期 | Token 缺失或失效 |
| 403 | 无权限 | 非管理员访问管理接口 |
| 429 | 频率限制 | 请求过于频繁 |
| 500 | 系统异常 | 服务器内部错误 |
| 502 | 外部服务异常 | 豆包 API 调用失败 |

### 6.1.4 鉴权方式

- **方式**: Bearer Token
- **位置**: HTTP Header `Authorization`
- **格式**: `Authorization: Bearer <token>`
- **获取**: 调用登录接口获得
- **有效期**: 7 天（Redis 控制）

### 6.1.5 Content-Type

- 请求（非文件上传）: `application/json; charset=utf-8`
- 请求（文件上传）: `multipart/form-data`
- 响应: `application/json; charset=utf-8`

## 6.2 认证接口

### 6.2.1 用户登录

```
POST /api/auth/login
```

**Request Body:**

```json
{
  "username": "admin",
  "password": "123456"
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | String | 是 | 用户名，3-50 字符 |
| password | String | 是 | 密码，6-32 字符 |

**Response (200):**

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "nickname": "管理员",
    "role": "ADMIN",
    "expireIn": 604800
  }
}
```

**Response (400):**

```json
{
  "code": 400,
  "message": "用户名或密码错误",
  "data": null
}
```

## 6.3 AI 对话接口

### 6.3.1 AI 对话（SSE 流式）

```
POST /api/chat/completion
```

**Headers:** `Authorization: Bearer <token>`
**Response Content-Type:** `text/event-stream`

**Request Body:**

```json
{
  "prompt": "帮我写一个 Spring Boot 用户注册接口",
  "image": null
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| prompt | String | 是 | 对话输入文本 |
| image | String | 否 | 图生文时传入 base64 data URL，格式 `data:image/jpeg;base64,xxx` |

**SSE 流式响应:**

```
data: {"token":"以下是"}
data: {"token":"用户注"}
data: {"token":"册接口"}
data: {"token":"的实现"}
data: {"done":true}
```

| 事件 | 触发时机 |
|------|---------|
| `{"token":"..."}` | 每生成一个文本片段，前端逐 token 追加渲染 |
| `{"done":true}` | 流结束，对话已保存到数据库 |

**HTTP 非流式错误响应:**

```json
{
  "code": 400,
  "message": "提示词不能为空",
  "data": null
}
```

## 6.4 文生图接口

### 6.4.1 生成图片

```
POST /api/t2i/generate
```

**Headers:** `Authorization: Bearer <token>`

**Request Body:**

```json
{
  "prompt": "赛博朋克风格的猫，霓虹灯，雨夜",
  "negativePrompt": "模糊，低质量，畸形",
  "size": "2K",
  "style": "赛博朋克",
  "watermark": false
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| prompt | String | 是 | 正向提示词，1-2000 字符 |
| negativePrompt | String | 否 | 反向提示词，0-1000 字符 |
| size | String | 否 | 默认 `2K`。可选值：`1K` / `2K` / `4K` / `宽x高` |
| style | String | 否 | 画风：`写实` / `二次元` / `插画` / `3D` / `赛博朋克` |
| watermark | Boolean | 否 | 默认 `false` |

**Response (200):**

```json
{
  "code": 200,
  "message": "图片生成成功",
  "data": {
    "recordId": 1024,
    "imageUrl": "http://localhost:9000/ai-text-image/t2i/1/xxx.png?X-Amz-Algorithm=...",
    "size": "2K",
    "style": "赛博朋克",
    "generateType": "TEXT_TO_IMAGE",
    "createdAt": "2026-07-16T14:30:22"
  }
}
```

**Response (429) 重复提交:**

```json
{
  "code": 429,
  "message": "请勿频繁提交相同绘图请求",
  "data": null
}
```

## 6.6 我的作品接口

### 6.6.1 分页查询作品

```
GET /api/works?page=0&size=20&type=TEXT_TO_IMAGE&startDate=2026-07-01&endDate=2026-07-16
```

**Headers:** `Authorization: Bearer <token>`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | Integer | 否 | 页码，从 0 开始，默认 0 |
| size | Integer | 否 | 每页条数，默认 20，最大 100 |
| type | String | 否 | 筛选类型：`TEXT_TO_IMAGE` / `IMAGE_TO_IMAGE` / `CHAT` / 空表示全部 |
| startDate | String | 否 | 开始日期，格式 `yyyy-MM-dd` |
| endDate | String | 否 | 结束日期，格式 `yyyy-MM-dd` |

**Response (200):**

```json
{
  "code": 200,
  "message": "查询成功",
  "data": {
    "content": [
      {
        "recordId": 1024,
        "thumbnailUrl": "http://localhost:9000/ai-text-image/t2i/1/xxx?X-Amz-Algorithm=...",
        "prompt": "赛博朋克风格的猫",
        "size": "2K",
        "style": "赛博朋克",
        "generateType": "TEXT_TO_IMAGE",
        "imageStatus": "SUCCESS",
        "createdAt": "2026-07-16T14:30:22"
      }
    ],
    "page": 0,
    "size": 20,
    "totalElements": 42,
    "totalPages": 3
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| content | Array | 作品列表，按创建时间倒序 |
| page | int | 当前页码 |
| size | int | 每页条数 |
| totalElements | int | 总记录数 |
| totalPages | int | 总页数 |

## 6.9 前端-后端联调注意事项

### 6.9.1 Token 传递

```javascript
// 前端 Axios 拦截器
axios.interceptors.request.use(config => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// 响应拦截：401 时跳转登录页
axios.interceptors.response.use(
  response => response,
  error => {
    if (error.response?.status === 401) {
      localStorage.removeItem('token');
      window.location.href = '/login';
    }
    return Promise.reject(error);
  }
);
```

### 6.9.2 图片加载处理

MinIO Presigned URL 有效期为 1 小时，前端展示图片时无需额外处理：

```html
<img :src="item.imageUrl" alt="生成图片" />
```

如果图片加载失败（403/过期），调用刷新接口获取新 URL。

### 6.9.3 跨域配置

```java
// Spring Boot CORS 配置
@Configuration
public class WebMvcConfig implements WebMvcConfigurer {
    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/api/**")
                .allowedOrigins("http://localhost:3000") // 前端地址
                .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
                .allowCredentials(true)
                .maxAge(3600);
    }
}
```

### 6.9.4 错误处理优先级

前端收到非 200 响应时，按以下逻辑处理：

```
401 → 清除 Token → 跳转登录页
429 → 弹出提示"操作太频繁，请稍后再试"
502 → 弹出提示"AI 服务暂时不可用"
500 → 弹出提示"系统异常，请联系管理员"
400 → 显示具体的参数错误信息
```
