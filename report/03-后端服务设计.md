## 3.2 分层职责

### Controller 层

负责接收 HTTP 请求、参数校验、调用 Service、返回结果。所有 Controller 统一返回 `AjaxJsonResult<T>` 格式。

```java
@RestController
@RequestMapping("/api")
public class T2IController {

    private final T2IService t2iService;

    @PostMapping("/t2i/generate")
    public AjaxJsonResult<ImageResultVO> generate(
            @RequestBody @Valid T2IRequest request,
            @RequestHeader("Authorization") String token) {
        // Token 已被拦截器解析，通过 RequestContext 获取 userId
        Long userId = AuthContext.getCurrentUserId();
        return t2iService.generateImage(userId, request);
    }
}
```

### ChatController（SSE 流式对话）

```java
@RestController
@RequestMapping("/api/chat")
public class ChatController {

    private final ChatService chatService;

    @PostMapping(value = "/completion", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
    public SseEmitter streamCompletion(
            @RequestBody @Valid ChatRequest request,
            @RequestHeader("Authorization") String token) {
        Long userId = AuthContext.getCurrentUserId();

        // 创建 SseEmitter，超时 120 秒（豆包 API 可能较慢）
        SseEmitter emitter = new SseEmitter(120_000L);

        // 异步调用豆包 API，通过 SseEmitter 逐块推送
        chatService.streamCompletion(userId, request, emitter);

        return emitter;
    }
}
```

### ChatServiceImpl（RxJava Observable → SseEmitter）

```java
@Service
@Slf4j
public class ChatServiceImpl implements ChatService {

    private final ChatRecordRepository chatRecordRepository;

    @Override
    public void streamCompletion(Long userId, ChatRequest request, SseEmitter emitter) {
        ArkService arkService = ArkServiceUtil.getArkService();

        // 构建文生文/图生文请求（含多模态图片）
        CompletionRequest completionRequest = buildCompletionRequest(request);

        // 订阅 Ark SDK 流式响应（返回 Observable）
        Observable<CompletionResponse> observable = arkService
                .streamCompletions(completionRequest);

        observable.subscribe(
            response -> {
                // 每收到一个 token，推送给前端
                String token = extractToken(response);
                if (token != null && !token.isBlank()) {
                    emitter.send(SseEmitter.event()
                            .data("{\"token\":\"" + escapeJson(token) + "\"}"));
                }
            },
            error -> {
                log.error("SSE 流异常", error);
                emitter.completeWithError(error);
            },
            () -> {
                // 流结束：保存完整对话到数据库
                saveChatRecord(userId, request, fullAnswer);
                emitter.send(SseEmitter.event()
                        .data("{\"done\":true}"));
                emitter.complete();
            }
        );
    }
}
```

### Service 层

核心业务逻辑层。每一层职责单一，通过接口隔离。

| Service 实现 | 核心方法 | 职责 |
|-------------|---------|------|
| AuthServiceImpl | `login()` / `logout()` / `validateToken()` | 校验账号密码、签发/销毁 Token |
| ChatServiceImpl | `streamCompletion()` (SSE) | 文生文 + 图生文流式对话 |
| T2IServiceImpl | `generateImage()` | 调用豆包文生图、存储结果 |
| I2IServiceImpl | `uploadSourceImage()` / `generateImage()` | 上传底图、调用豆包图生图 |
| DoubaoImageServiceImpl | `textToImage()` / `imageToImage()` | 封装豆包 API 调用逻辑 |
| MinioServiceImpl | `uploadFile()` / `getPresignedUrl()` / `deleteFile()` | MinIO 文件操作 |
| HistoryServiceImpl | `listUserRecords()` / `deleteRecord()` | 作品查询、删除（含对话记录） |
| AdminUserServiceImpl | `createUser()` / `listUsers()` / `toggleUserStatus()` | 账号管理 |

## 3.3 关键业务逻辑实现

### 3.3.1 文生图核心流程 (T2IServiceImpl)

```java
@Service
@Slf4j
@RequiredArgsConstructor
public class T2IServiceImpl implements T2IService {

    private final DoubaoImageService doubaoImageService;
    private final MinioService minioService;
    private final ImageRecordRepository recordRepository;
    private final RedisTemplate<String, String> redisTemplate;

    @Override
    @Retryable(
        retryFor = {DoubaoApiException.class},
        maxAttempts = 3,
        backoff = @Backoff(delay = 1000)
    )
    public AjaxJsonResult<ImageResultVO> generateImage(Long userId, T2IRequest request) {
        // 1. 参数校验
        validateRequest(request);

        // 2. 防重复提交 (Redis 分布式锁, 5 秒过期)
        String lockKey = "t2i:lock:" + userId + ":" + request.getPrompt().hashCode();
        Boolean locked = redisTemplate.opsForValue()
                .setIfAbsent(lockKey, "1", Duration.ofSeconds(5));
        if (Boolean.FALSE.equals(locked)) {
            return AjaxJsonResult.error("429", "请勿频繁提交相同绘图请求");
        }

        try {
            // 3. 调用豆包文生图 API
            DoubaoImageResult doubaoResult = doubaoImageService.textToImage(
                request.getPrompt(),
                request.getSize(),
                request.getStyle(),
                request.getWatermark()
            );

            // 4. 下载图片并上传到 MinIO
            String objectName = String.format("t2i/%d/%s.%s",
                userId, UUID.randomUUID(), "png");
            String minioUrl = minioService.uploadFromUrl(
                doubaoResult.getImageUrl(),
                "ai-text-image",
                objectName
            );

            // 5. 写入 PostgreSQL 记录
            ImageRecord record = new ImageRecord();
            record.setUserId(userId);
            record.setGenerateType(GenerateType.TEXT_TO_IMAGE);
            record.setPrompt(request.getPrompt());
            record.setNegativePrompt(request.getNegativePrompt());
            record.setSize(request.getSize());
            record.setStyle(request.getStyle());
            record.setMinioPath(objectName);
            record.setImageStatus(ImageStatus.SUCCESS);
            record.setCreatedAt(LocalDateTime.now());
            recordRepository.save(record);

            // 6. 返回结果
            ImageResultVO vo = new ImageResultVO();
            vo.setRecordId(record.getId());
            vo.setImageUrl(minioService.getPresignedUrl("ai-text-image", objectName));
            vo.setSize(request.getSize());
            vo.setGenerateType("文生图");
            vo.setCreatedAt(record.getCreatedAt());

            return AjaxJsonResult.success(vo);

        } catch (DoubaoApiException e) {
            log.error("豆包 API 调用失败: userId={}, prompt={}", userId, request.getPrompt(), e);
            return AjaxJsonResult.error("502", "AI 绘图服务暂时不可用，请稍后重试");
        } finally {
            redisTemplate.delete(lockKey);
        }
    }
}
```

### 3.3.2 豆包 API 封装 (DoubaoImageServiceImpl)

参照火山引擎 Ark Java SDK 官方示例，封装为可复用的工具类：

```java
@Service
@Slf4j
public class DoubaoImageServiceImpl implements DoubaoImageService {

    private final ArkService arkService;

    public DoubaoImageServiceImpl() {
        String apiKey = System.getenv("ARK_API_KEY");
        if (apiKey == null || apiKey.isBlank()) {
            throw new IllegalStateException("ARK_API_KEY 环境变量未配置");
        }

        ConnectionPool pool = new ConnectionPool(5, 30, TimeUnit.SECONDS);
        Dispatcher dispatcher = new Dispatcher();
        dispatcher.setMaxRequests(10);

        this.arkService = ArkService.builder()
                .dispatcher(dispatcher)
                .connectionPool(pool)
                .apiKey(apiKey)
                .baseUrl("https://ark.cn-beijing.volces.com/api/v3")
                .build();
    }

    @Override
    public DoubaoImageResult textToImage(String prompt, String size,
                                          String style, Boolean watermark) {
        // 风格提示词预处理：不同风格自动添加描述
        String stylePrompt = enrichStylePrompt(prompt, style);

        GenerateImagesRequest request = GenerateImagesRequest.builder()
                .model("doubao-seedream-4-5-251128")
                .prompt(stylePrompt)
                .size(size)
                .sequentialImageGeneration("disabled")
                .responseFormat(ResponseFormat.Url)  // 返回 URL
                .stream(false)
                .watermark(watermark != null && watermark)
                .build();

        ImagesResponse response = arkService.generateImages(request);

        if (response.getData() == null || response.getData().isEmpty()) {
            throw new DoubaoApiException("豆包 API 返回数据为空");
        }

        String imageUrl = response.getData().get(0).getUrl();
        return new DoubaoImageResult(imageUrl);
    }

    @Override
    public DoubaoImageResult imageToImage(String sourceImageUrl,
                                           String prompt, Double strength,
                                           String size, String style) {
        // 图生图：将底图 URL 和参数传给豆包 API
        String stylePrompt = enrichStylePrompt(prompt, style);

        GenerateImagesRequest request = GenerateImagesRequest.builder()
                .model("doubao-seedream-4-5-251128")
                .prompt(stylePrompt)
                .image(sourceImageUrl)       // 参考图 URL
                .size(size)
                .sequentialImageGeneration("disabled")
                .responseFormat(ResponseFormat.Url)
                .stream(false)
                .watermark(true)
                .build();

        ImagesResponse response = arkService.generateImages(request);
        // ... 解析并返回
    }

    /** 根据画风自动扩充提示词 */
    private String enrichStylePrompt(String prompt, String style) {
        if (style == null || style.isBlank()) return prompt;

        return switch (style) {
            case "写实" -> prompt + "，摄影写实风格，8K超高清，真实光影，专业摄影";
            case "二次元" -> prompt + "，二次元动画风格，赛璐珞上色，日系动漫";
            case "插画" -> prompt + "，插画风格，水彩质感，手绘感，艺术感";
            case "3D" -> prompt + "，3D渲染风格，C4D，Octane渲染，体积光，材质细腻";
            case "赛博朋克" -> prompt + "，赛博朋克风格，霓虹灯，赛博格，未来城市";
            default -> prompt;
        };
    }
}
```

### 3.3.3 MinIO 服务封装 (MinioServiceImpl)

```java
@Service
@Slf4j
public class MinioServiceImpl implements MinioService {

    private final MinioClient minioClient;

    public MinioServiceImpl(
            @Value("${minio.endpoint}") String endpoint,
            @Value("${minio.access-key}") String accessKey,
            @Value("${minio.secret-key}") String secretKey) {
        this.minioClient = MinioClient.builder()
                .endpoint(endpoint)
                .credentials(accessKey, secretKey)
                .build();
    }

    @Override
    public String uploadFromUrl(String imageUrl, String bucket, String objectName) {
        try {
            // 确保桶存在
            if (!minioClient.bucketExists(BucketExistsArgs.builder().bucket(bucket).build())) {
                minioClient.makeBucket(MakeBucketArgs.builder().bucket(bucket).build());
            }

            // 从 URL 下载并上传
            URL url = new URL(imageUrl);
            try (InputStream is = url.openStream()) {
                minioClient.putObject(PutObjectArgs.builder()
                        .bucket(bucket)
                        .object(objectName)
                        .stream(is, -1, 10485760)
                        .contentType("image/png")
                        .build());
            }
            return objectName;
        } catch (Exception e) {
            log.error("MinIO 上传失败: bucket={}, object={}", bucket, objectName, e);
            throw new MinioException("图片上传存储失败");
        }
    }

    @Override
    public String getPresignedUrl(String bucket, String objectName) {
        try {
            return minioClient.getPresignedObjectUrl(GetPresignedObjectUrlArgs.builder()
                    .bucket(bucket)
                    .object(objectName)
                    .method(Method.GET)
                    .expiry(3600)  // 1 小时过期
                    .build());
        } catch (Exception e) {
            log.error("获取签名 URL 失败: bucket={}, object={}", bucket, objectName, e);
            return null;
        }
    }

    @Override
    public void deleteFile(String bucket, String objectName) {
        try {
            minioClient.removeObject(RemoveObjectArgs.builder()
                    .bucket(bucket)
                    .object(objectName)
                    .build());
        } catch (Exception e) {
            log.error("MinIO 删除失败: bucket={}, object={}", bucket, objectName, e);
        }
    }
}
```

## 3.4 全局异常处理

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(UnauthorizedException.class)
    public AjaxJsonResult<Void> handleUnauthorized(UnauthorizedException e) {
        return AjaxJsonResult.error("401", e.getMessage());
    }

    @ExceptionHandler(BusinessException.class)
    public AjaxJsonResult<Void> handleBusiness(BusinessException e) {
        return AjaxJsonResult.error("400", e.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public AjaxJsonResult<Void> handleValidation(MethodArgumentNotValidException e) {
        String msg = e.getBindingResult().getFieldErrors().stream()
                .map(f -> f.getField() + ": " + f.getDefaultMessage())
                .collect(Collectors.joining("; "));
        return AjaxJsonResult.error("400", msg);
    }

    @ExceptionHandler(Exception.class)
    public AjaxJsonResult<Void> handleException(Exception e) {
        log.error("系统异常", e);
        return AjaxJsonResult.error("500", "系统内部错误");
    }
}
```

## 3.5 鉴权拦截器

```java
@Component
public class AuthInterceptor implements HandlerInterceptor {

    private final RedisTemplate<String, String> redisTemplate;

    // 白名单：不需要登录的接口
    private static final List<String> WHITELIST = List.of(
        "/api/auth/login",
        "/api/auth/register",
        "/swagger-ui/**",
        "/v3/api-docs/**"
    );

    @Override
    public boolean preHandle(HttpServletRequest request,
                              HttpServletResponse response,
                              Object handler) {
        String path = request.getRequestURI();
        if (WHITELIST.stream().anyMatch(path::startsWith)) {
            return true;
        }

        String token = request.getHeader("Authorization");
        if (token == null || token.isBlank()) {
            throw new UnauthorizedException("未登录，请先登录");
        }

        // 从 Redis 校验 Token
        String userId = redisTemplate.opsForValue().get("session:" + token);
        if (userId == null) {
            throw new UnauthorizedException("登录已过期，请重新登录");
        }

        // 设置当前用户上下文
        AuthContext.setCurrentUserId(Long.parseLong(userId));
        return true;
    }

    @Override
    public void afterCompletion(HttpServletRequest request,
                                 HttpServletResponse response,
                                 Object handler, Exception ex) {
        AuthContext.clear(); // 清理 ThreadLocal
    }
}
```
