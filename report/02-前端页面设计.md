# 2. 前端页面设计

## 2.1 页面路由规划

| 路径 | 页面 | 访问权限 | 描述 |
|------|------|---------|------|
| `/login` | 登录页 | 公开 | 用户登录 |
| `/chat` | AI 对话页 | 登录用户 | 文生文 / 图生文（SSE 流式） |
| `/t2i` | 文生图页 | 登录用户 | 文本生成图片 |
| `/i2i` | 图生图页 | 登录用户 | 图片生成图片 |
| `/works` | 我的作品 | 登录用户 | 历史作品查看与管理 |
| `/admin/users` | 账号管理 | 管理员 | 用户管理后台 |
| `/*` | 404 | 公开 | 未匹配路由 |

## 2.2 导航栏

所有登录后页面共享顶部导航栏：

```
┌─────────────────────────────────────────────────────────────┐
│  AI 生图平台  [AI对话] [文生图] [图生图] [我的作品]  用户 ▼  │
│              [账号管理]（仅管理员可见）                       │
└─────────────────────────────────────────────────────────────┘
```

### 页面布局

```
┌─────────────────────────────────────┐
│              AI 生图平台              │
│                                     │
│  ┌─────────────────────────────┐    │
│  │       账号密码登录           │    │
│  │                             │    │
│  │  ┌───────────────────────┐  │    │
│  │  │ 请输入用户名           │  │    │
│  │  └───────────────────────┘  │    │
│  │  ┌───────────────────────┐  │    │
│  │  │ 请输入密码             │  │    │
│  │  └───────────────────────┘  │    │
│  │                             │    │
│  │  ☑ 记住登录状态             │    │
│  │                             │    │
│  │  ┌───────────────────────┐  │    │
│  │  │       登 录           │  │    │
│  │  └───────────────────────┘  │    │
│  │                             │    │
│  │  ❌ 用户名或密码错误        │    │
│  └─────────────────────────────┘    │
└─────────────────────────────────────┘
```

### 交互功能

| 元素 | 行为 |
|------|------|
| 用户名输入框 | 非空校验，失去焦点时校验 |
| 密码输入框 | 密码隐藏显示切换，非空校验 |
| 记住登录状态 | 勾选后将 Token 存入 localStorage，否则存入 sessionStorage |
| 登录按钮 | 提交表单，调用 `/api/auth/login`，成功则跳转至 `/t2i` |
| 错误提示 | 账号不存在 / 密码错误 / 参数为空 三种独立提示 |
| 未登录拦截 | 路由守卫检测 Token 是否存在，不存在则重定向至 `/login` |

### 后端 API

```
POST /api/auth/login
Request:  { "username": "admin", "password": "xxx" }
Response: { "code": 200, "data": { "token": "xxx", "nickname": "管理员" } }
```

## 2.4 AI 对话页 (ChatPage)

### 页面布局

```
┌──────────────────────────────────────────────────────────┐
│  AI 生图平台  [AI对话][文生图][图生图][我的作品]  admin ▼ │
├──────────────────────────────────────────────────────────┤
│  ┌─ 对话消息区（流式渲染）─────────────────────────────┐  │
│  │                                                     │  │
│  │  用户: 帮我写一个 Spring Boot 用户注册接口            │  │
│  │  ──────────────────────────────────────────────      │  │
│  │  AI: 以下是用户注册接口的实现...                      │  │
│  │      @PostMapping("/api/register")                   │  │
│  │      public Result register(...)                     │  │
│  │  ──────────────────────────────────────────────      │  │
│  │  用户: [上传图片 puppy.jpg] 这张图里有什么？          │  │
│  │  ──────────────────────────────────────────────      │  │
│  │  AI: 这张图片中显示一只黄色的幼犬...                  │  │
│  │  ┌──────────────────────────────────────────────┐    │
│  │  │  ▋ AI 正在输入...                              │    │
│  │  └──────────────────────────────────────────────┘    │
│  └──────────────────────────────────────────────────────┘
│                                                          │
│  ┌─ 输入区 ──────────────────────────────────────────┐  │
│  │  [📎 图片] ┌──────────────────────────────┐ [➤ 发送]│  │
│  │            │ 输入消息，Enter 发送...        │         │  │
│  │            └──────────────────────────────┘         │  │
│  └────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

### 交互功能

| 元素 | 行为 |
|------|------|
| 消息输入框 | Enter 发送，Shift+Enter 换行 |
| 图片上传按钮 | 点击选择图片，支持 jpg/png/webp，≤10MB |
| 发送按钮 | 提交消息，开始 SSE 流式请求 |
| 流式渲染 | 逐 token 渲染 AI 回复，打字机效果 |
| 图片预览 | 上传后输入框上方显示缩略图，可移除 |
| 对话历史 | 页面加载时从后端获取最近 30 条记录 |
| 清空对话 | 清空当前对话上下文（不删除数据库记录） |

### 后端 API

```
POST /api/chat/completion  (SSE stream)
Authorization: Bearer <token>
Content-Type: application/json

Request:
{
  "prompt": "帮我写一个用户注册接口",
  "image": null  或 "data:image/jpeg;base64,xxx"
}

Response: text/event-stream (SSE)
data: {"token": "以下是"}
data: {"token": "用户注"}
data: {"token": "册接口"}
data: {"done": true}
```

## 2.5 文生图页 (TextToImagePage)

### 页面布局

```
┌──────────────────────────────────────────────────────────┐
│  AI 生图平台    [文生图] [图生图] [我的作品]   admin ▼   │
├──────────────────────────────┬───────────────────────────┤
│  📝 正向提示词                │      生成预览区域          │
│  ┌────────────────────────┐  │                           │
│  │ 一只赛博朋克风格的猫...  │  │   ┌─────────────────┐   │
│  └────────────────────────┘  │   │                 │   │
│  📝 反向提示词 (可选)         │   │  生成结果大图     │   │
│  ┌────────────────────────┐  │   │                 │   │
│  │ 模糊, 低质量, 变形...   │  │   └─────────────────┘   │
│  └────────────────────────┘  │                           │
│                              │  [下载] [保存到我的作品]   │
│  ⚙️ 参数配置                 │  [重新生成]               │
│  尺寸: [2K ▼]  数量: [1 ▲]  │                           │
│  画风: [写实|二次元|插画|3D] │                           │
│  相似度: ═══●══════ 0.6     │                           │
│                              │                           │
│  ┌────────────────────────┐  │                           │
│  │    🎨 开始生成          │  │                           │
│  └────────────────────────┘  │                           │
│                              │  ⌛ 正在生成... 45%       │
│  加载动画区域                 │                           │
└──────────────────────────────┴───────────────────────────┘
```

### 参数面板说明

| 参数 | 控件类型 | 默认值 | 说明 |
|------|---------|--------|------|
| 正向提示词 | TextArea | 空 | 描述想要生成的画面，上限 2000 字符 |
| 反向提示词 | TextArea | 空 | 描述不想要的元素，上限 1000 字符 |
| 图片尺寸 | Select | 2K | 1K / 2K / 4K / 自定义宽高 |
| 生成数量 | InputNumber | 1 | 1-4 张 |
| 画风 | Radio Group | 写实 | 写实 / 二次元 / 插画 / 3D / 赛博朋克 |
| 相似度 | Slider | 0.6 | 0-1，控制与提示词的一致程度 |
| 水印 | Switch | 关 | 是否添加 AI 生成水印 |

### 交互流程

1. 用户填写提示词，配置参数
2. 点击「开始生成」，按钮变为加载状态，显示进度条
3. 后端异步返回生成结果
4. 结果展示在右侧预览区域
5. 用户可下载、保存、重新生成

## 2.9 通用组件

| 组件 | 用途 |
|------|------|
| Navbar | 顶部导航栏，显示 Logo、菜单、用户信息 |
| AuthGuard | 路由守卫，检查 Token 是否存在，未登录跳转登录页 |
| AdminGuard | 管理员路由守卫，检查用户角色 |
| LoadingSpinner | 加载动画组件 |
| ErrorModal | 错误弹窗提示 |
| ImagePreview | 图片预览弹窗 |
| Pagination | 分页组件 |
| EmptyState | 空状态占位提示 |
