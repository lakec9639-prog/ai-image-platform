### 4.1.2 用户表 (users)

```sql
CREATE TABLE users (
    id              BIGSERIAL       PRIMARY KEY,
    username        VARCHAR(50)     NOT NULL UNIQUE,
    password        VARCHAR(255)    NOT NULL,       -- BCrypt 加密
    nickname        VARCHAR(50),                    -- 显示昵称
    role            VARCHAR(20)     NOT NULL DEFAULT 'USER',  -- USER / ADMIN
    status          VARCHAR(10)     NOT NULL DEFAULT 'ENABLED', -- ENABLED / DISABLED
    created_at      TIMESTAMP       NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMP       NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_users_username ON users(username);
CREATE INDEX idx_users_status   ON users(status);
```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 自增主键 |
| username | VARCHAR(50) | 用户名，唯一索引 |
| password | VARCHAR(255) | BCrypt 加密后的密码 |
| nickname | VARCHAR(50) | 显示昵称 |
| role | VARCHAR(20) | USER（普通用户）/ ADMIN（管理员） |
| status | VARCHAR(10) | ENABLED（启用）/ DISABLED（禁用） |

### 4.1.3 生图记录表 (image_records)

```sql
CREATE TABLE image_records (
    id                  BIGSERIAL       PRIMARY KEY,
    user_id             BIGINT          NOT NULL REFERENCES users(id),
    generate_type       VARCHAR(20)     NOT NULL,   -- TEXT_TO_IMAGE / IMAGE_TO_IMAGE
    prompt              TEXT            NOT NULL,   -- 正向提示词
    negative_prompt     TEXT,                       -- 反向提示词
    size                VARCHAR(20)     NOT NULL,   -- 2K / 4K / 1920x1080
    style               VARCHAR(50),                -- 画风
    similar_strength    DECIMAL(3,2),               -- 相似度强度 (0-1)
    source_minio_path   VARCHAR(500),               -- 图生图：原图 MinIO 路径
    result_minio_path   VARCHAR(500)    NOT NULL,   -- 成品图 MinIO 路径
    result_format       VARCHAR(10)     DEFAULT 'png', -- png / jpeg
    image_status        VARCHAR(20)     NOT NULL DEFAULT 'SUCCESS',
                                                    -- SUCCESS / FAILED / PENDING
    fail_reason         TEXT,                       -- 失败原因
    doubao_request_id   VARCHAR(100),               -- 豆包 API 请求 ID（用于追踪）
    created_at          TIMESTAMP       NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMP       NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_records_user_id       ON image_records(user_id);
CREATE INDEX idx_records_generate_type ON image_records(generate_type);
CREATE INDEX idx_records_created_at    ON image_records(created_at DESC);
CREATE INDEX idx_records_user_time     ON image_records(user_id, created_at DESC);
```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 自增主键 |
| user_id | BIGINT | 用户 ID，外键关联 users 表 |
| generate_type | VARCHAR(20) | TEXT_TO_IMAGE / IMAGE_TO_IMAGE |
| prompt | TEXT | 正向提示词，上限 2000 字符 |
| negative_prompt | TEXT | 反向提示词，可选 |
| size | VARCHAR(20) | 图片尺寸 |
| style | VARCHAR(50) | 画风 |
| similar_strength | DECIMAL(3,2) | 图生图重绘强度 |
| source_minio_path | VARCHAR(500) | 图生图时，原图在 MinIO 的路径 |
| result_minio_path | VARCHAR(500) | 成品图在 MinIO 的路径 |
| image_status | VARCHAR(20) | SUCCESS / FAILED / PENDING |
| doubao_request_id | VARCHAR(100) | 豆包 API 请求追踪 ID |

### 4.1.4 对话记录表 (chat_records)

```sql
CREATE TABLE chat_records (
    id                  BIGSERIAL       PRIMARY KEY,
    user_id             BIGINT          NOT NULL REFERENCES users(id),
    chat_type           VARCHAR(20)     NOT NULL,   -- TEXT_TO_TEXT / IMAGE_TO_TEXT
    prompt              TEXT            NOT NULL,   -- 用户输入
    image_minio_path    VARCHAR(500),               -- 图生文参考图路径（可空）
    answer              TEXT            NOT NULL,   -- AI 回复完整文本
    created_at          TIMESTAMP       NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_chat_user_time ON chat_records(user_id, created_at DESC);
```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 自增主键 |
| user_id | BIGINT | 用户 ID，外键关联 users |
| chat_type | VARCHAR(20) | TEXT_TO_TEXT（文生文）/ IMAGE_TO_TEXT（图生文） |
| prompt | TEXT | 用户输入文本 |
| image_minio_path | VARCHAR(500) | 图生文时用户上传的参考图 MinIO 路径 |
| answer | TEXT | AI 完整回复文本 |
| created_at | TIMESTAMP | 创建时间 |

> 对话记录不关联 MinIO 成品桶，只有图生文时才在 MinIO 临时存储参考图片。

## 4.2 Redis 缓存设计

### 4.2.1 Key 命名规范

| Key 模式 | 数据结构 | 过期时间 | 说明 |
|---------|---------|---------|------|
| `session:{token}` | String | 7 天 | 用户登录会话，value = userId |
| `user:info:{userId}` | String | 1 天 | 用户基本信息 JSON |
| `works:recent:{userId}` | List | 1 小时 | 最近 20 条作品列表（JSON 数组） |
| `t2i:lock:{userId}:{hash}` | String | 5 秒 | 文生图防重复提交锁 |
| `i2i:lock:{userId}:{hash}` | String | 5 秒 | 图生图防重复提交锁 |
| `rate:limit:{userId}` | String | 1 分钟 | 接口限流计数器 |

### 4.2.2 会话缓存逻辑

```
用户登录成功
  → 生成唯一 Token (UUID)
  → Redis SET session:{token} → userId  (过期时间 7 天)
  → Token 返回给前端

用户每次请求
  → 拦截器从 Header 取 Token
  → Redis GET session:{token} → 校验是否存在
  → 存在则放行，不存在返回 401

用户退出登录
  → Redis DEL session:{token}
  → Token 立即失效
```

### 4.2.3 作品列表缓存逻辑

```
用户访问「我的作品」
  → 尝试从 Redis 取 works:recent:{userId}
  → 命中 → 直接返回
  → 未命中 → 查 PostgreSQL → 写入 Redis → 返回

用户生成新作品
  → 删除 Redis works:recent:{userId}（强制下次刷新）
```

### 4.2.4 限流逻辑

```java
// 使用 Redis + 滑动窗口限流：每分钟最多 10 次
public boolean isRateLimited(Long userId) {
    String key = "rate:limit:" + userId;
    Long count = redisTemplate.opsForValue().increment(key);
    if (count == 1) {
        redisTemplate.expire(key, Duration.ofMinutes(1));
    }
    return count > 10; // 超过 10 次/分钟，限流
}
```

## 4.3 MinIO 对象存储设计

### 4.3.1 桶规划

| 桶名 | 用途 | 访问策略 | 文件命名规则 |
|------|------|---------|------------|
| `ai-text-image` | 文生图成品 | 私有时效签名 | `t2i/{userId}/{uuid}.png` |
| `ai-img2img-out` | 图生图成品 | 私有时效签名 | `i2i/{userId}/{uuid}.png` |
| `ai-source-img` | 用户上传底图 | 私有时效签名 | `source/{userId}/{timestamp}_{filename}` |

### 4.3.2 文件生命周期

```
上传阶段:
  用户上传底图 → MinIO ai-source-img 桶 → 返回临时路径
  调用豆包 API → 获取成品 URL → 下载 → MinIO 成品桶

访问阶段:
  前端请求图片 → 后端生成 Presigned URL (1 小时有效) → 返回给前端

删除阶段:
  用户删除作品 → 数据库删除记录 → MinIO 删除文件
```

### 4.3.3 桶创建 (Docker Compose 初始化)

```yaml
version: '3.8'
services:
  minio:
    image: minio/minio:latest
    ports:
      - "9000:9000"
      - "9001:9001"
    environment:
      MINIO_ROOT_USER: minioadmin
      MINIO_ROOT_PASSWORD: minioadmin
    volumes:
      - minio_data:/data
    command: server /data --console-address ":9001"
    healthcheck:
      test: ["CMD", "mc", "ready", "local"]
      interval: 30s
      timeout: 10s
      retries: 3

  init-buckets:
    image: minio/mc:latest
    depends_on:
      minio:
        condition: service_healthy
    entrypoint: >
      /bin/sh -c "
      mc alias set myminio http://minio:9000 minioadmin minioadmin;
      mc mb myminio/ai-text-image;
      mc mb myminio/ai-img2img-out;
      mc mb myminio/ai-source-img;
      mc policy set download myminio/ai-text-image;
      mc policy set download myminio/ai-img2img-out;
      mc policy set download myminio/ai-source-img;
      echo 'Buckets created successfully';
      "
```

## 4.4 数据完整性与安全

### 4.4.1 外键约束

```sql
-- 用户与作品的关联
ALTER TABLE image_records
ADD CONSTRAINT fk_records_user
FOREIGN KEY (user_id) REFERENCES users(id);

-- 删除用户时保留作品（仅标记禁用，不级联删除）
-- 所以外键使用 NO ACTION
```

### 4.4.2 权限过滤（查询级）

```sql
-- 所有作品查询必须带 user_id 条件
SELECT * FROM image_records
WHERE user_id = :currentUserId   -- 关键：强制归属过滤
ORDER BY created_at DESC
LIMIT 20 OFFSET 0;
```

### 4.4.3 数据备份策略

| 组件 | 备份方式 | 频率 | 保留 |
|------|---------|------|------|
| PostgreSQL | pg_dump | 每日 | 7 天 |
| MinIO | 数据卷快照 | 每日 | 7 天 |
| Redis | RDB 持久化 | 按配置 | 按配置 |
